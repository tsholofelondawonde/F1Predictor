# Accessibility

- Semantic HTML, keyboard navigation, visible focus states.
- Proper labels on every form control; accessible error messages.
- ARIA only when semantic HTML can't express the same thing.
- Sufficient color contrast; meaningful alt text on informative images,
  empty alt on decorative ones.
- No interaction that depends solely on hover.
