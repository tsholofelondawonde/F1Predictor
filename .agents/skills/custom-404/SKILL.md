# Custom 404

- Use the framework's native not-found mechanism if it has one.
- Visually consistent with the rest of the app; clear "not found" message;
  a way back to the home page.
- Responsive at every breakpoint.
- Never leak internal routing structure or stack traces.
- Give it appropriate metadata (and noindex, if it shouldn't be indexed).
