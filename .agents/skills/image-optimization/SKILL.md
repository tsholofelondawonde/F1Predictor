# Image Optimization

- Compress before shipping; prefer WebP/AVIF where supported.
- Set explicit dimensions to avoid layout shift.
- Lazy-load below-the-fold images; don't lazy-load the critical
  above-the-fold ones.
- Meaningful alt text on informative images, empty alt on purely
  decorative ones.
