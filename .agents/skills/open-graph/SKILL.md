# Open Graph

- Minimum: og:title, og:description, og:image, og:url, og:type —
  page-specific where it matters.
- Default OG image for the app; allow per-page override where supported.
- OG image URL must be absolute and publicly reachable — never a
  localhost URL in production metadata.
