# Responsive Design

- Check the existing design system/breakpoints before adding new ones —
  don't invent a parallel set.
- Must hold up at mobile, tablet, and desktop.
- No horizontal overflow unless intentional.
- Navigation and forms stay usable on small screens; touch targets stay
  tappable.
