# SEO Metadata

- Every public page gets a unique title and description that actually
  describe its content — no copy-pasted defaults, no keyword stuffing.
- Use the framework's metadata API rather than hand-rolled tags where one
  exists.
- Avoid duplicate descriptions across pages where avoidable.
